# Why this desk has no front end

Masking rules, runs, exceptions and review evidence are records. A coding agent can run the import, query those records and draft the weekly handover without a separate application.

A screen helps people browse large rule sets, compare field previews and manage many users. This base instead provides a CLI and branded read-only HTML. There is no mobile application, drag-and-drop rule editor, real-time collaboration or automatic refresh listener. Local execution works offline after dependencies are installed, although the optional document font uses a web request.

DataMasker also provides native Salesforce masking and automation features. Those are more than screens. This base processes exported CSV copies and records review evidence. Native integrations require a separately tested implementation. It is useful for an operator preparing test fixtures without connecting to Salesforce at runtime.
